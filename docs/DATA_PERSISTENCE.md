# LoopMuse 데이터 보관과 복원

## 저장 위치와 파일 구조

- 실행 중에는 앱 내부 Room DB와 설정 저장소를 사용한다. 앱 업데이트 시 Room 마이그레이션으로 기존 곡 정보를 보존한다.
- 사용자가 Android 폴더 선택기로 지정한 공유 폴더에는 복원용 JSON 파일을 저장한다. 권장 위치는 `내부 저장소/Documents/LoopMuse`다. 음악 파일이 있는 폴더 아래에 `LoopMuse` 폴더를 만들어 선택해도 된다.
- 정상 상태에서 자동 백업 파일은 선택 폴더의 `loopmuse_current.json` 하나다. 변경 사항을 모아 이 파일을 갱신한다.
- 덮어쓰기 전 정상 백업 하나는 선택 폴더의 `LoopMuse_Recovery/loopmuse_previous.json`에 보관한다. 복원·초기화 직전 안전 복사본도 `LoopMuse_Recovery`에 별도로 둔다. 이는 자동 백업 파일 손상이나 잘못된 복원에 대비한다.
- 예전 버전이 만든 날짜별 `loopmuse-*.json`과 예전 형식 `loopmuse_backup.json`은 자동 삭제하지 않는다. 설정의 **이전 백업 정리**에서 파일을 확인하고 개별 삭제하거나 날짜별 자동 백업을 일괄 정리할 수 있다. 현재 자동 백업 파일은 이 메뉴에서 삭제할 수 없다.
- 앱 전용 외부 폴더는 앱 삭제 시 함께 지워지므로 백업 위치로 권장하지 않는다. Android 시스템 자동 백업도 기기 설정에 따라 이용 가능하지만 공유 폴더 백업을 대체하지 않는다.

## 사용자 흐름

1. 새 설치 또는 이 기능이 처음 포함된 업데이트 후 첫 실행에서 현재 기기의 데이터 수를 확인한다. Android가 이미 자동 복원한 정보가 있다면 **현재 정보로 계속**을 누른다.
2. 이전 정보를 쓰려면 **백업 폴더 선택** 또는 **백업 파일 선택**을 누른다. 현재 자동 백업을 우선 표시하고 이전 파일 목록은 접어 둔다.
3. **교체 복원**은 현재 데이터를 백업 내용으로 바꾸고, **병합**은 합치며, **새로 시작**은 현재 데이터만 비운다. 교체와 초기화 직전에는 안전 복사본을 만든다.
4. 자동 백업 폴더를 지정하면 곡 정보, 재생목록, 선택 폴더, 재생 기록, 알람 변경을 모아 자동 저장한다. 재생목록 오른쪽의 설정 아이콘에서 **보관 및 복원** 페이지를 열어 백업 상태, 파일 위치, 마지막 성공 시각을 확인할 수 있다.
5. 이미 `loopmuse_current.json`이 있는 폴더를 자동 백업 위치로 지정해 현재 정보를 저장하려면 덮어쓰기 확인을 거친다. 이전 정보를 쓰려는 경우 먼저 교체 복원 또는 병합을 선택한다.
6. 앱을 삭제하고 다시 설치하면 Android가 외부 폴더 접근 허가를 지우므로 같은 폴더를 한 번 다시 선택해야 한다. 앱이 임의의 개인 폴더를 자동 검색할 수는 없다.

## 백업과 복원 정책

- 새 내용을 임시 파일에 기록하고 다시 읽어 SHA-256 무결성을 검증한 뒤 현재 파일을 갱신한다. 정상적인 기존 현재 파일은 갱신 전에 복구 폴더에 복사한다. 쓰기 실패 시 검증된 임시 파일이나 이전 복구본이 남을 수 있으며, 설정에서 확인할 수 있다.
- 손상되거나 저장이 중단된 파일은 복원 버튼을 비활성화하고 목록에 상태를 표시한다. 현재 자동 백업을 제외한 파일은 정리할 수 있다.
- 예전 `loopmuse_backup.json`은 곡 메타데이터 병합에 사용할 수 있다. 예전 형식에는 재생목록과 알람이 없어 교체 복원에는 사용할 수 없다.
- 곡 메타데이터 충돌은 `lastUpdated`가 더 최근인 항목을 선택한다. 동일한 재생목록 ID는 곡 ID와 기록을 합치고 현재 설정을 유지한다. 선택 폴더는 중복을 제거하고 알람은 내용이 같은 항목을 중복 등록하지 않는다.

## 범위와 주의점

- 음악 파일 자체는 백업하지 않는다. 다른 기기나 달라진 경로에서 복원하면 음악 폴더를 다시 선택해야 한다.
- 파일 제공자가 일시적으로 사용 불가능하거나 앱 종료 직후 삭제되면 마지막 변경이 백업 파일에 반영되지 않을 수 있다. 앱을 삭제하기 전에 설정에서 마지막 성공 시각을 확인하고 필요하면 **지금 백업**을 누른다.
- `내부 저장소/Documents/LoopMuse/loopmuse_current.json`처럼 경로를 보여준다. 클라우드 저장소 등 일반 파일 경로가 없는 제공자는 제공자와 폴더 이름을 표시한다.
- 알람은 복원, 기기 재부팅, 앱 업데이트 후 다시 예약한다. 정확한 알람 권한이 없으면 예약 실패를 표시한다.
