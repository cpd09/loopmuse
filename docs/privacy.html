LoopMuse(이하 "앱")는 사용자의 소중한 개인정보를 보호하며, 「개인정보 보호법」 및 Google Play 개발자 정책을 준수하기 위하여 다음과 같이 개인정보 처리방침을 수립·공개합니다.

1. 수집하는 개인정보 항목 및 수집 방법

앱은 원활한 서비스 제공을 위해 최소한의 정보만을 처리하며, 음원 파일 자체를 서버로 수집하거나 업로드하지 않습니다.

구분 항목 수집 목적 / 처리 방식
Google 로그인 Google 계정 고유 식별자(UID), 이메일 주소, 프로필 이름, 선택한 라운지 닉네임. 글·댓글에는 닉네임(미설정 시 Google 이름)이 공개되며 이메일은 작성자 이름으로 공개하지 않습니다. 이름 변경 시 해당 계정의 기존 글·댓글에도 반영됩니다. Firebase Authentication을 통한 사용자 식별, 세션 유지 및 계정 관리
라운지(공감 게시판) 게시글 본문, 공유 곡명·가수명·링크, 댓글/답글 내용, 공감 반응(좋아요/싫어요), 신고 내역, 작성자 식별자(UID) Firebase Cloud Firestore에 저장되어 커뮤니티 공유, 공감 통계 산출, 부적절한 게시글 신고 및 제재 처리에 활용
Firebase 서비스 기술 정보 로그인·서버 기능을 사용할 때 접속 IP, 요청 기능 이름, Firebase UID, 앱·SDK 식별 정보와 버전, 기기 운영체제·모델 등의 서비스 정보가 처리될 수 있습니다. Firebase Functions SDK는 알림에 사용할 수 있는 FCM 토큰도 자동 처리할 수 있습니다. LoopMuse는 현재 이 토큰으로 푸시 알림을 보내지 않습니다. Firebase가 로그인 보안, 앱 서버 요청 및 서비스 제공·유지에 처리합니다. Firebase Installations ID는 앱 설치 단위 식별자로 사용됩니다. 관련 정보의 처리·보유는 각 Firebase 서비스 기준을 따릅니다.
기기 로컬 데이터 (비수집) 로컬 재생 목록, 청취 이력, 알람 설정, 저장된 가사, 사용자 차단(Block) 목록 앱의 Firebase 서버로 업로드하지 않고 기기에 저장합니다. 이용규칙 동의 정보도 기기에 저장합니다. Android 및 기기 설정에 따라 운영체제의 자동 백업·복원 대상이 될 수 있습니다.

2. 외부 제3자 서비스 연동

앱은 특정 기능 수행 시 다음과 같은 외부 서비스를 활용할 수 있으며, 이 과정에서 필요한 최소한의 음악 검색 메타데이터가 전달될 수 있습니다.

  • Google Firebase (Google LLC): 사용자 인증(Firebase Auth), 라운지 데이터베이스(Cloud Firestore), 서버 기능(Cloud Functions)에 활용됩니다. SDK 요청 처리 중 IP 주소, 요청 기능명, Firebase 식별자, 앱/SDK 및 기기 기술정보와 FCM 토큰이 처리될 수 있습니다. 이 정보는 인증 보안 및 서비스 요청 제공 등에 사용됩니다. LoopMuse는 현재 FCM 토큰으로 푸시 알림을 보내지 않습니다.
  • LRCLIB: 가사 검색 시 곡명·가수명 및 가능한 경우 앨범명·재생시간을 전달합니다. 반환된 가사는 기기에 저장됩니다.
  • ListenBrainz: 음악 발견 화면에서 개인별 청취목록이나 LoopMuse 계정 식별자를 보내지 않고 공개 통계를 요청합니다. 외부 서버는 요청을 처리할 때 IP 주소 등 표준 접속 정보를 처리할 수 있습니다.
  • 외부 음악 링크: 사용자가 곡 검색/링크를 누를 경우 YouTube 등 외부 웹사이트/앱으로 이동할 수 있습니다.

3. 개인정보의 보유 및 이용 기간

  1. 탈퇴 요청 전까지 계정·라운지 자료를 보유합니다. 탈퇴 요청 즉시 라운지 이용을 잠그고 2일간 복구 기간을 둡니다. 이 기간에는 같은 Google 계정으로 로그인해 ‘탈퇴 취소 및 계정 복구’를 선택할 수 있습니다.
  2. 2일 안에 복구하지 않으면 시간 단위 정리 작업에서 계정과 게시글·댓글·반응·신고·프로필을 영구 삭제합니다. 요청 후 예정 시각이 지나면 다음 정리 작업 때 진행되며, 장애가 있으면 완료가 늦어질 수 있습니다. 본인 게시글의 하위 자료도 삭제됩니다.
  3. 완전 삭제 뒤 재가입 악용을 막기 위해 Google 계정 제공자 식별자만 삭제 완료 후 7일 동안 보관하며, 시간 단위 정리 작업이 만료 표식을 지웁니다(정상 운영 시 7일 만료 후 최대 약 1시간). 이메일·이름·게시글 내용은 이 제한 표식에 저장하지 않습니다.
  4. 삭제된 Firebase UID의 보안 상태 표식은 기존 로그인 토큰의 재사용 방지를 위해 완료 후 2시간부터 정리 대상이 되며, 정상 운영 시 최대 약 3시간 안에 제거됩니다. 장애 시 두 표식의 삭제가 늦어질 수 있습니다.

4. 개인정보의 파기 절차 및 방법

관리자가 숨김 처리한 글과 댓글·반응은 관리자만 조회할 수 있습니다. 숨김 처리 시점부터 관리자가 설정한 보관 기간(기본 365일)이 지나면 매시간 실행되는 정리 작업에서 자동 삭제하며, 장애 시 지연될 수 있습니다. 보관 기간 변경은 기존 숨김 글에도 적용됩니다. 다시 공개한 글은 해당 정리 대상에서 제외됩니다. 회원 탈퇴 시에는 보관 기간과 관계없이 본인 자료를 함께 삭제합니다.

  • 파기 절차: 이용자가 탈퇴를 요청하거나 목적이 달성된 개인정보는 내부 방침 및 관련 법령에 따라 파기됩니다.
  • 파기 방법: 전자적 파일 형태로 저장된 데이터는 복구 및 재생이 불가능한 기술적 방법을 사용하여 완전히 삭제합니다.

5. 계정 및 데이터 영구 삭제 요청 방법 (Account Deletion)

Google Play 데이터 보호 정책에 따라, 이용자는 언제든지 자신의 계정과 관련 데이터를 직접 삭제하거나 운영자에게 삭제를 요청할 수 있습니다.

방법 A. LoopMuse 앱에서 자동 삭제 요청

  1. LoopMuse 앱을 실행합니다.
  2. 화면 상단 플레이리스트 영역 오른쪽 끝의 전체설정(톱니바퀴 아이콘)을 누릅니다.
  3. 설정 메뉴에서 '앱 정보'를 누릅니다.
  4. 하단 [계정 관리] 섹션의 '회원 탈퇴 및 계정 삭제'를 선택합니다.
  5. 확인 창에서 [탈퇴하기]를 누르고 현재 로그인한 Google 계정으로 본인 확인을 합니다. 라운지 이용은 즉시 제한됩니다. 2일 안에 다시 로그인해 [탈퇴 취소 및 계정 복구]를 선택하면 계정을 복구할 수 있습니다. 복구하지 않으면 2일 후 서버 정리 작업에서 계정과 활동 자료를 영구 삭제합니다.
  6. 완전 삭제된 뒤 같은 Google 계정으로는 7일이 지나야 다시 가입할 수 있습니다.

방법 B. 웹/이메일을 통한 삭제 요청 (앱을 이미 삭제한 경우)

  • 처리 절차: 본인 확인 후 탈퇴 예약을 진행합니다. 요청 즉시 라운지 접근을 제한하고 2일간 복구할 수 있으며, 2일 안에 앱에 로그인해 복구하지 않으면 예정 시각 이후 서버 정리 작업에서 계정 및 연계 자료를 영구 삭제합니다.
