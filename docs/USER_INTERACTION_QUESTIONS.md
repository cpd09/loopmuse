# 사용자 상호작용 확인 질문

이 문서는 실제 사용 중 겪은 증상을 확인하기 위한 질문지입니다. 해당하는 항목에 표시하고, 가능하면 기기와 Android 버전, 사용한 재생목록, 곡 이름, 조작 순서, 발생 빈도를 함께 적어 주세요. 아래의 추가 항목은 코드상 가능성이 보인 상황이며 실제 발생 여부는 확인되지 않았습니다.

## 이번 수정과 관련된 동작 재확인

- [ ] 같은 곡을 연속으로 두 번 누를 때 두 번째 터치가 무시되거나, 화면을 스크롤하고 돌아온 뒤에야 다시 반응한 적이 있나요?
- [ ] 곡 행을 살짝 움직이며 누른 뒤 그 곡을 다시 눌러도 반응하지 않은 적이 있나요?
- [ ] 다중 선택 모드를 켜거나 끈 직후, 어떤 곡은 재생되고 어떤 곡은 선택되는 등 곡마다 터치 결과가 달랐나요?
- [ ] 마지막 선택 곡을 해제한 다음 곡을 누르면 예상과 다르게 곧바로 재생된 적이 있나요?
- [ ] 현재곡을 선택했는데 선택 표시가 보이지 않거나, 아래 재생 카드가 선택한 곡과 다르게 표시된 적이 있나요?

## 추가로 확인하고 싶은 상황

- [ ] 다중 선택 상태에서 다른 재생목록으로 바꾸거나 검색 결과를 열었을 때 이전 목록의 선택 표시나 선택 재생 상태가 남은 적이 있나요? 그 뒤 이전곡·다음곡을 누르면 무음이나 앱 종료가 있었나요?
- [ ] 좋아요 필터를 켜거나 끌 때 선택한 곡의 표시 또는 재생 순서가 예상과 달라진 적이 있나요?
- [ ] 선택곡 재생 중 현재 들리는 곡만 선택 해제했을 때 그 곡이 끝까지 계속 재생되는 동작이 불편했나요? 바로 다음 선택곡으로 넘어가길 원하나요?
- [ ] 기존 사용자 재생목록을 편집할 때 `선택된 곡` 숫자와 화면에 보이는 곡 수가 다르거나, 전체 선택/해제를 누른 뒤 예상하지 않은 곡이 포함되거나 빠진 적이 있나요?
- [ ] 곡/폴더 선택을 빠르게 변경했을 때 곡 수나 목록이 이전 선택 결과로 돌아간 적이 있나요?
- [ ] 곡/폴더 선택 항목을 모두 해제하고 완료했을 때 Music·Downloads의 곡이 다시 나타나 당황한 적이 있나요?
- [ ] 좋아요 아이콘을 빠르게 두 번 누르면 원래 상태로 돌아오지 않거나, 다른 곡의 좋아요가 바뀐 적이 있나요?
- [ ] 서로 다른 두 파일이 항상 함께 선택되거나, 한 곡을 눌렀는데 다른 곡이 재생되거나, 목록이 갑자기 오류를 낸 적이 있나요? 있다면 두 파일의 전체 경로를 알려 주세요.
- [ ] 곡 제목의 왼쪽 또는 오른쪽 끝, 특히 좋아요·태그 편집 아이콘 가까이를 눌렀을 때 행 선택 대신 아이콘 동작이 실행된 적이 있나요?
- [ ] 재생목록의 오른쪽 스크롤 막대를 조작할 때 의도하지 않은 곡이 실행되거나, 손을 뗀 뒤에도 목록이 이동한 적이 있나요?
- [ ] TalkBack, 키보드, 스위치 접근 등 터치 외 입력으로 곡 행을 선택하거나 재생할 때 어려움이 있었나요?
- [ ] 알람, 재생목록 편집, 검색 창을 열고 닫은 뒤 이전 화면의 선택·재생 상태가 예상과 다르게 바뀐 적이 있나요?
- [ ] 검색 결과를 보고 앱을 닫았다 다시 열었을 때 목록 이름이나 곡이 비어 있는 상태로 남은 적이 있나요?
- [ ] 여러 알람을 저장하거나 반복 요일을 골랐을 때 일부 알람만 울리거나 다음 주기에 다시 울리지 않은 적이 있나요?
- [ ] 기기 회전·시스템의 앱 재생성 후 곡 표시, 선택 표시, 재생 상태가 갑자기 이전 값으로 돌아간 적이 있나요?
