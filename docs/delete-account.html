LoopMuse(com.loopmuse7205.music)는 사용자의 개인정보 자기결정권을 존중하며, 언제든지 계정과 서버에 보관된 모든 데이터를 영구히 파기할 수 있는 두 가지 경로를 제공합니다.

1. 앱 내에서 직접 즉시 탈퇴하기 (가장 빠름)

📱 인앱 회원 탈퇴 단계:

  1. LoopMuse 앱 실행 후 메인 화면으로 이동합니다.
  2. 화면 상단 플레이리스트 영역 오른쪽의 '전체설정(⚙️ 톱니바퀴)' 아이콘을 누릅니다.
  3. 목록에서 '앱 정보' 메뉴를 선택합니다.
  4. 화면 하단 [계정 관리] 섹션의 '회원 탈퇴 및 계정 삭제'를 선택합니다.
  5. 탈퇴 확인 팝업에서 [탈퇴하기]를 누르면 즉시 구글 계정 인증 정보가 해제되고, 서버의 사용자 정보가 즉각 영구 삭제됩니다.

2. 웹/이메일을 통한 계정 및 데이터 삭제 요청

앱을 이미 삭제하셨거나 기기 접근이 어려운 경우, 아래 이메일로 요청해 주시면 지체 없이 처리해 드립니다.

  • 처리 기한: 본인 확인 후 영업일 기준 7일 이내에 Firebase Authentication 및 Cloud Firestore 상의 모든 데이터를 영구 삭제하고 완료 메일을 회신합니다.

3. 삭제되는 데이터 및 보존 정책

⚠️ 삭제 범위 안내:
• 삭제되는 데이터: Google 로그인 계정 고유 식별자(UID), 이메일, 닉네임, 라운지 활동 데이터 일체
• 로컬 기기 데이터: 사용자의 휴대폰에 저장된 재생목록, 청취 이력, 알람 설정은 앱을 기기에서 삭제(Uninstall)할 때 함께 완전히 제거됩니다.
• 복구 불가: 영구 삭제가 완료된 후에는 기존 계정 및 활동 기록을 복구할 수 없습니다.
